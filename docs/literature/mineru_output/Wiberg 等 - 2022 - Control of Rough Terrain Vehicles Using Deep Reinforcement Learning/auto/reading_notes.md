# Wiberg 等 2022 阅读笔记

文献：`Control of Rough Terrain Vehicles Using Deep Reinforcement Learning`

阅读目标：

- 提炼 RL 环境设计：`observation`、`action`、`reward`、`termination`、训练设定
- 为本课题识别可迁移点与不宜直接照搬的部分

阅读状态：

- 已完成一轮围绕 RL 环境设计的问答式梳理
- 当前重点不是复述全文，而是提炼任务定义与训练组织逻辑

## 1. 论文的任务到底是什么

### 1.1 任务定义

这篇论文的任务不是泛泛的“具有地形适应能力”，而是：

- 控制一台 16 吨林业车辆 `Xt28`
- 直接控制 `6` 个车轮、`6` 个主动悬架、`2` 个车架铰接关节，共 `14` 维连续动作
- 让车辆在粗糙地形中到达指定目标位姿
- 同时兼顾安全、能耗、滑移、地面作用和环境友好性

### 1.2 结果表现与任务定义的区别

论文中提到的：

- 能处理阻挡性障碍
- 能应对最高 `27°` 坡度
- 限制轮胎打滑
- 平稳、直立地通过地形
- 智能利用主动悬架

这些更接近训练结果和性能表现，不是最原始的任务定义本身。

### 1.3 成功与失败

训练 episode：

- 到达目标则结束
- 或在课程设置下达到 `400` 或 `500` 步后结束

提前终止包括：

- 车辆越过目标
- 横滚超过 `25°`
- 底盘任意部位与地形发生 terminal contact

其中，target reaching 的判据在文中测试图注里写得较明确：

- 距离目标位置小于 `0.3 m`
- 相对目标朝向误差小于 `9°`

## 2. Observation 设计逻辑

### 2.1 三类 observation

论文的 observation 可以整理为三组：

1. 地形感知
- 车辆局部高度图
- 范围约 `15 x 10 m`
- 分辨率约 `30 x 20`
- 随车辆平移并按车辆航向对齐

2. 本体状态 / proprioception
- 车辆坐标系下的速度
- 世界坐标系下的横滚、俯仰
- 车架铰接关节角
- 各悬架相关状态，如活塞位移
- 轮胎纵向 slip ratio
- 轮胎侧滑角
- 各车轮载荷，并按车重归一化

3. 任务相关信息
- 相对于车辆参考系的目标信息
- 可概括为 `(x, y, phi)` 形式的相对目标位姿误差

### 2.2 Observation 背后的结构

它不是简单的“地图 + 状态”，而是：

`局部地形几何 + 本体动力学 + 轮地接触质量 + 相对目标信息`

这说明作者希望策略同时具备：

- 前视地形判断能力
- 对自身姿态/运动状态的感知能力
- 对牵引与接触状态的感知能力
- 对目标任务的定向能力

## 3. Action 设计

### 3.1 直接控制对象

策略直接输出 `14` 维连续动作，对应：

- `6` 个车轮
- `6` 个主动悬架
- `2` 个车架 articulation joints

### 3.2 启示

这篇论文采用的是高维、底层、连续控制，而不是传统车辆常见的高层速度/转向命令。

因此它更适合被理解为：

- 多执行器协同控制问题
- 不是单纯的导航问题

## 4. Reward 设计逻辑

### 4.1 先让任务学会，再约束行为质量

论文中最重要的 reward 设计思想不是“奖励项很多”，而是：

1. 先用最小 reward 让策略学会完成主任务
2. 再观察学出来的坏行为
3. 再逐步加入行为质量约束

作者明确指出：

- `r_tar + r_prog * r_head`
  已经对“快速到达目标”很关键
- 但这还不足以保证安全、高效、环保的驾驶

因此后续才加入 roll、speed、forces、slip、energy、sidewall 等项。

### 4.2 Reward 功能分组

1. 主任务奖励
- `r_tar`
- `r_prog`
- `r_head`

作用：

- 给出 success signal
- 给出 progress 的 dense guidance
- 鼓励接近目标时具备合理朝向

2. 行为质量项
- `r_roll`
- `r_speed`
- `r_forces`
- `r_slip_parallel`
- `r_slip_perp`
- `r_energy`
- `r_side`

作用：

- 抑制翻覆风险
- 抑制过快行驶
- 促进轮载均匀
- 限制纵向/侧向滑移
- 抑制不必要的能耗与剧烈动作
- 防止利用轮胎侧壁取巧

3. 终止条件
- roll 超过硬阈值
- terminal chassis-ground contact
- 超过最大步数
- beyond target

这里要特别区分：

- `r_roll` 不是终止条件本身，而是连续惩罚
- `r_side` 也不是终止条件，而是显式惩罚项

### 4.3 为什么要加这些 reward

如果只保留“到达目标”，策略可能学出一系列不可接受但在奖励上有效的行为：

- 高速硬冲
- 大侧倾前进
- 纵向空转或侧滑换进度
- 把载荷集中到少数轮子
- 用高频、粗暴的执行器动作换取短期收益
- 通过轮胎侧壁接触来取 traction

因此这些 reward 的核心作用不是“追求更完美”，而是：

- 阻止策略利用仿真漏洞或工程上不接受的局部最优

### 4.4 Reward 函数形式背后的意义

- 高斯/指数型衰减：适合“越接近 0 越好”的量，如 roll、force imbalance、slip
- 阈值以上才快速衰减：适合 speed 这类“不要超限”的量
- 多轮乘积：要求所有轮子同时表现良好，而不是平均上看起来还行
- 线性负项：适合统计 sidewall contact 这类事件型代价
- 能耗惩罚：抑制粗暴、抖动、浪费的控制动作

### 4.5 可学习的 reward 设计流程

这篇论文最值得借鉴的 reward 设计流程不是“先想公式”，而是：

1. 先定义主任务成功是什么
2. 再枚举“虽然完成任务但不可接受”的行为
3. 再判断每类问题应该写成：
- soft penalty
- hard termination
- evaluation metric
4. 最后才决定函数形式和参数

## 5. Training 与 Evaluation 设计

### 5.1 Episode 初始化

训练时：

- 车辆部署在地形上的随机位置
- 初始朝向随机
- 先让车辆落地并稳定
- 在开始前的一小段仿真里，对悬架施加一个简单控制器

这一初始化的目的不是训练主策略，而是：

- 让每次 episode 开始时具有更自然的悬架/姿态状态差异
- 避免 reset 后所有初始状态过于机械和僵硬

### 5.2 Target 采样

- 目标距离固定为 `20 m`
- 相对当前车头方向，在一个由 curriculum 控制的角度范围内采样
- 目标位置沿扇形弧按二次分布采样，以增加边缘位置概率
- 目标朝向再在相对区间内均匀采样

这说明 target sampling 本身就是任务难度控制器，不是随便随机。

### 5.3 Curriculum

论文将课程分为四个 lesson，按固定顺序递进：

1. 平坦地形 + Perlin noise，重点建立基础驾驶技能，如加速、转向、速度控制
2. 在基础地形上加入半椭球障碍，重点学习利用高度图避开不可通过物体
3. 使用更强起伏地形与不同尺寸障碍，学习更复杂的粗糙地形通过
4. 在扫描得到的真实地形上训练，含坡地、巨石和沟壑

课程不只是调 reward，而是同时调：

- 地形复杂度
- 障碍物类型
- target heading difficulty
- episode 最大步数

### 5.4 Evaluation

- 训练使用 `10` 个并行环境
- 每个环境对应不同地形
- 每 `25k` steps 做一次独立评估
- 评估地形不参与训练
- 评估使用确定性初始条件与确定性动作选择

这体现了一个很重要的训练原则：

- 不只看训练 reward
- 要用独立 evaluation protocol 检查泛化能力

## 6. 目前提炼出的核心方法论

这篇论文最值得保留的不是某一条具体 reward 或某一个超参数，而是以下方法论：

1. 把 rough-terrain control 明确建模成一个可执行的 RL 任务
- 明确 `goal`
- 明确 `action`
- 明确 `success/failure`

2. 用结构化 observation 支撑策略
- 局部地形前视
- 本体状态
- 接触/滑移相关信息
- 任务目标信息

3. 用“主任务 + 行为质量”的 reward 结构组织多个目标

4. 用 curriculum 逐步提升训练难度，而不是一开始把复杂因素全部塞进来

5. 用训练/评估地形分离来支撑“地形适应能力”的论证

## 7. 对本课题的当前启发

### 7.1 强可迁移的思想

- `reward = 主任务 + 行为质量约束`
- `curriculum 先基础后复杂`
- `训练集/评估集地形分离`

### 7.2 强参考但不应直接视为默认方案

- 局部高度图
  - 如果任务确实需要前视地形适应，这一设计很值得借鉴
- reset 做自然化初始化
  - 更偏训练稳定性工程经验，而不是研究问题本体

### 7.3 当前不能直接视为本课题结论的部分

- 目标位姿任务
  - 论文里自然成立，因为其主任务就是 waypoint-reaching
  - 但本课题的任务形态尚未最终确定，因此不能直接照搬

## 8. 当前阅读结论

这篇论文最重要的启发不是“必须做目标位姿导航”，而是：

- 用前视地形感知和高维控制处理 rough terrain
- 用“主任务 + 行为质量”的 reward 结构约束策略行为
- 用 curriculum 与独立 evaluation 组织出可信的训练流程

换句话说，本论文最值得迁移的是 RL 问题组织方法，而不是任务表面形式本身。
