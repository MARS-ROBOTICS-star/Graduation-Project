## 1. 坐标系定义

推荐用于第一版台阶模型的坐标系：

| 项目 | 当前确认 |
|---|---|
| $x$ 轴 | 车辆前进方向，前车体方向为正 |
| $y$ 轴 | 车辆左侧为正 |
| $z$ 轴 | 竖直向上 |
| 中车体原点 $O_m$ | 建议取 `body_car_chassis` 质心 |
| 前车体原点 $O_f$ | 建议取 `head_car_chassis` 质心 |
| 后车体原点 $O_r$ | 建议取 `tail_car_chassis` 质心 |
| 球铰连接点 | 在准静态模型中建议用相对中车体质心的连接点坐标；前 / 后车体本地坐标也在下文给出 |
| 轮心坐标 | 下文默认给相对各自车体质心的坐标；另给 USD 初始装配中的世界轴线位置作校核 |

当前 USD 静态资产确认：

- stage `meters_per_unit = 1.0`
- up axis 为 `Z`
- USD 检查结果中，前 / 中 / 后轮轴线世界 $x$ 位置约为 `+0.552977 / 0 / -0.552977 m`。

本节后续推导默认使用各模块质心坐标系；USD 世界坐标仅用于初始装配校核，不直接进入局部几何方程。

当前 `wheel_speed_allocator.py` 的实现细节需要单独注意：

- 它把前轮局部向量写成 `(l1 - b_f, ±d1/2, h1)`。
- 它把后轮局部向量写成 `(l3 + b_r, ±d3/2, h3)`。

## 7. 台阶参数

### 7.1 第一版理论模型建议

为了先推最大可爬台阶高度，建议第一版理论模型使用理想垂直台阶：

$$
z_s(x)=
\begin{cases}
0, & x < 0 \\
h, & x \ge 0
\end{cases}
$$

| 参数 | 当前建议 | 含义 | 单位 |
|---|---|---|---|
| $h$ | 待求 | 最大台阶高度 | m |
| 台阶是否为垂直棱边 | 是 | 第一版理论模型 | - |
| 台阶边缘是否倒角 | 否 | 第一版理论模型 | - |
| 倒角半径 | `0` | 第一版理论模型 | m |
| 台阶宽度 / 高台面长度 | 需由实验场景另定 | 第一版理论模型中可先设为足够长 | m |
| 台阶前是否有水平地面 | 是 | 第一版理论模型 | - |

### 7.2 当前 Stage1 仿真地形

当前 Stage1 主线并不是单个理想台阶，而是 heightfield terrain generator。

| 参数 | 当前值 |
|---|---:|
| terrain tile length | `8.0 m` |
| terrain tile width | `8.0 m` |
| horizontal scale | `0.1 m` |
| vertical scale | `0.005 m` |
| num rows | `20` |
| num cols | `10` |

当前训练列：

| 列范围 | 地形 |
|---|---|
| col00 | flat |
| col01 | slope down |
| col02 | slope up |
| col03-col04 | uneven rough |
| col05-col07 | stairs down |
| col08-col09 | discrete obstacles |

`stairs down` 的生成函数：

- 台阶宽度 `step_width_m = 0.31 m`
- 每级台阶高度幅值：

$$
h_{step} = 0.05 + 0.13 \cdot d_{stairs}
$$

- 其中 $d_{stairs} = row / (num_rows - 1)$。
- 当前 `num_rows = 20`，因此 row 19 对应 $d_{stairs}=1.0$。
- 因为当前是 `stairs down`，源码中高度符号取负。
- row 1 公式高度约 `0.057 m`，经 `vertical_scale = 0.005 m` 量化后实际为 `0.055 m`。
- row 19 对应每级高度 `0.180 m`。
- `_pyramid_stairs_terrain(..., platform_size=3.0)` 生成的是阶梯地形，不是单个孤立垂直台阶。

`discrete obstacles` 的当前最大障碍高度：

$$
h_{obs,max} = 0.05 + 0.1159 \cdot difficulty
$$

其中 `difficulty = row / 20`。在 `vertical_scale = 0.005 m` 量化后，当前最高 row19 的实际最大障碍高度 / 坑深为 `0.16 m`。
